# Currículo-site Douglas Jelinsky

- [ ] **Apresentar o currículo completo em uma única página responsiva**
  - Usar todas as informações disponíveis no currículo fornecido: perfil, contato, endereço, Facebook, educação, cursos, habilidades com percentuais, experiências profissionais, frase de destaque e os marcadores Foco / Comprometimento / Resultados.
  - Incluir também a experiência adicional: Tratamento e Pintura — Almoxarife — 04/02/2019 a 12/01/2020.
  - Manter a direção visual aprovada de painel operacional, com fundo azul-marinho, acentos em azul elétrico, coluna lateral e linha do tempo vertical.

- [ ] **Oferecer edição direta no navegador sem login**
  - O controle “Editar currículo” deve habilitar edição inline nos textos e percentuais visíveis.
  - O controle “Salvar edições” deve persistir o conteúdo no `localStorage` do navegador.
  - O controle “Restaurar original” deve remover as edições salvas e retornar ao conteúdo original.

- [ ] **Disponibilizar impressão / salvamento em PDF**
  - O controle “Baixar / imprimir PDF” deve abrir a impressão do navegador.
  - A folha deve usar layout A4, ocultar controles de edição e preservar a hierarquia visual.

- [ ] **Garantir adaptação para telas menores**
  - A coluna lateral deve se reorganizar para leitura vertical em celulares.
  - A linha do tempo deve permanecer legível, sem cortes horizontais.

- [ ] **Entregar uma página estática pronta para preview e publicação**
  - Servir `/manus-routes.json` com a rota `/`.
  - Manter HTML, CSS e JavaScript separados e sem dependências externas obrigatórias.
